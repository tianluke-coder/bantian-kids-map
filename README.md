## 2. 腾讯地图怎么连（三种方式，按场景选）

### 方式 A：默认代理模式（本指南采用，免 key）

骨架文件里的连接代码就是标准模板，四个要点：

```html
<!-- 1. 代理配置必须放在 SDK 之前 -->
<script>
  window._TMapSecurityConfig = {
    serviceHost: 'http://127.0.0.1:__WB_HTTP_PORT__/_TMapService/_wbt/__WB_TMAP_SECRET__',
  };
</script>
<!-- 2. SDK 地址不带 ?key= -->
<script src="https://map.qq.com/api/gljs?v=1.exp"></script>
```

```js
// 3. 初始化：GCJ-02 坐标系；容器必须有固定高度（骨架里是 100vh）
var map = new TMap.Map('map', {
  center: new TMap.LatLng(22.6005, 114.0600),
  zoom: 15,
  viewMode: '2D'
});
```

**六条硬规则（踩了就不显示或报错）：**
1. `_TMapSecurityConfig` 必须在 SDK `<script>` 之前；
2. SDK URL 不带 `?key=`；
3. 坐标系是 **GCJ-02（火星坐标）**——别直接贴 GPS 原始坐标（WGS-84），会偏几百米；
4. 地图容器必须有固定高度（`height: 100vh` 或像素值）；
5. 类名规律：**图层类带 Multi 前缀**（`MultiMarker / MultiPolygon / MultiLabel / MultiCircle`），**样式类不带**（`MarkerStyle / PolygonStyle / LabelStyle`）；搜索等服务类要先加载 `libraries=service`；
6. **不要传 `mapStyleId`**（自定义底图样式需在腾讯位置服务控制台单独激活，默认 key 不支持）；也不要用 `fetch` 手拼代理地址发请求（会 403 / LatLng NaN）——搜索等能力一律走 SDK 类，例如 `TMap.service.Search`。
7. **图层切换用 `setVisible()` 或 `setMap()`**（文档明确支持，`setMap(null)` 即解绑）；不要用 `map: null` 去构造常驻图层再切换，构造阶段的空底图引用会让后续代码静默中断。
8. `LabelStyle` 的白底/边框/圆角**必须配 `padding`（或 width+height）才生效**，否则只有纯文字。
9. **覆盖层（横幅/按钮/提示）的 z-index 必须大于 1000**——腾讯地图 GL JS 内部控制层的 z-index 就是 1000，压不住的元素会被地图盖住且点击不到（本项目实测踩坑，表现为“有图标没文字、按钮没反应”）。
10. `TMap.service.Search` 的搜索方法是 `searchNearby / searchRegion / searchRectangle`（Promise 风格），不是构造函数回调；且要求 Key **关闭 SN 签名校验**（控制台 → Key 设置里取消勾选），否则所有搜索类调用返回 `status:111 签名验证失败`。

### 方式 B：自己的 key（正式上线时必须）

代理模式只在 WorkBuddy 环境内有效。**上线后 127.0.0.1 代理不存在，底图会挂**，所以顺序是：

1. 开发/演示阶段：用方式 A 在 WorkBuddy 预览里跑；
2. 上线前：到[腾讯位置服务官网](https://lbs.qq.com/)申请自己的 key，把模板改成：
   ```html
   <script src="https://map.qq.com/api/gljs?v=1.exp&key=你的key"></script>
   ```
   并删掉 `_TMapSecurityConfig` 整段；
3. 密钥安全：个人使用配 **Referer 白名单**；商用必须走后端代理。前端明文 key 可被嗅探，这是官方明确提示的风险。

### 方式 C：自定义底图样式（本项目不用，说明为什么）

卡通底图（糖果色道路、圆角建筑）在腾讯地图里靠 `mapStyleId`，但**默认 key 不支持**，需要控制台单独激活。所以本项目的卡通化走**覆盖层路线**：底图保持默认，上面盖 Q 版图标（`MultiMarker` + SVG data URI）、糖果色区块（`MultiPolygon`）、大标签（`MultiLabel`）。这既是合规最快的做法，也让"儿童模式/标准模式"切换变成一行代码（换图标尺寸 + 标签显隐）。

### 附：POI 坐标校准（搜索/地理编码）

```js
// 在页面里跑（SDK 需带 libraries=service，请求自动走代理）
new TMap.service.Search({
  keyword: '机器人6S店',
  location: new TMap.LatLng(22.604808, 114.061698),
  pageSize: 1,
  success: function (res) {
    var p = res.data[0];
    console.log(p.title, p.location.lat, p.location.lng); // GCJ-02
  }
});
```

> SDK 加载地址改为 `https://map.qq.com/api/gljs?v=1.exp&libraries=service`。
> 也可以直接让 WorkBuddy 联网检索坐标（见 Step 2 提示词），二选一。

**又挖出一个真凶：路线不通不是白名单，是 Key 配额**
线上实测 `routeMeta` 仍是"示意线路"，抓包发现所有 `apis.map.qq.com/ws/direction/v1/walking/` 请求都返回 **HTTP 200**，但 body 是 `{"status":121,"message":"此key每日调用量已达到上限"}`：
| 请求方式 | 返回 |
|---|---|
| 带 Referer `https://bantian-robot-kids-map.app.workbuddy.host/` | `status:121` 配额用尽（**说明域名白名单已经通过**） |
| 不带 Referer | `status:110` 来源域名未被授权 |

即白名单早就配好了，卡住的是**文件里内置的那个共享 Key 的每日配额被打满**（同一把 Key 大家都在用）。110 和 121 都是 HTTP 200 + JSON 里带 status，只看网络面板的 200 会误判成"接口通了"。

**为此加的改动**：
- **常驻「Key」按钮**（右下角工具栏，路线/徽章旁边）：打开 Key 设置面板，填自己的 Key 存 localStorage，下次打开自动生效，不用改文件、不用重新部署。
- **Key 优先级修正**：原本写成 `window.KIDS_MAP_KEY || savedKey`，内置共享 Key 永远压过用户填的 Key——等于用户填了也没用。改成 `savedKey || window.KIDS_MAP_KEY`，**只要填过自己的 Key 就一律用自己的**。
- **降级提示说人话**：`fetchWalking` 把失败状态码透传出来，按 110/121/3xx 分别提示"白名单没包含当前域名"/"Key 今日配额已用完"/"Key 无效或未开通 WebService"，并在提示里指向「Key」按钮。实测线上已正确弹出"Key 今日配额已用完…"。

**取景框像素实测**（截图后用 PIL 找紫色边框 `#7F77DD` 的长直线定位框边界，再逐个匹配 13 种盒子主色的像素簇中心）：紫色框 x:306–972 / y:0–576，13 枚盒子落在 x:560–717 / y:156–551，**全部在框内**。注：别拿"整片淡紫色填充"去定位框——填充是 `rgba(127,119,221,0.12)`，跟底图灰色混完几乎一个色，会误判成铺满全屏；要用 2px 的纯色边框。

**教训**：调整标记坐标时，必须**同步复查取景框、高亮多边形、降级示意线路**这三条共用同一组边界的地方，改一处忘另外两处就会出现"框不住内容"这种回退。

## 5. 避坑清单

1. **合规红线**：国内公开发布的地图底图只能用腾讯 / 高德 / 百度 / 天地图；OSM 仅限内测拉白模；成品定位是"风格化场景"不是测绘产品；不标国界和敏感设施。
2. **key 安全**：代理模式零 key 但仅限 WorkBuddy 环境；上线必须换自己的 key + Referer 白名单；不要把 key 提交进 git 或资料库。
3. **坐标系**：GCJ-02，GPS 原始坐标偏几百米；换底图厂商时坐标体系可能不同（高德/腾讯 GCJ-02，百度 BD-09）。
4. **性能**：图标用 SVG data URI 而不是大 PNG；POI 超过 30 个时按缩放级别分级显示。
5. **字体许可**：OFL 可放心用；CC-BY 要署名；别用来路不明的"免费商用"字体。
6. **儿童内容**：无外链广告、无内购诱导弹窗、无强制收集个人信息。
7. **演示与上线是两套**：WorkBuddy 预览（代理模式）↔ 公网链接（自己的 key），切换点只有 SDK 那一行。

## 7. 升级路线（什么时候离开"最快路径"）

- 想要**真正的 3D Q 版街区**（而不是平面地图 + 图标）→ 换路线 A：blender-osm 拉白模 → Blender Q 版化 → glTF → three.js。工期 ×3，效果上限高得多。
- 想要**线下联动**（在真实机器人大道上"抓"机器人）→ 加 LBS 触发 + 小程序定位，注意隐私合规（不收集用户位置落库）。
- 想要**多人共享集章**→ 上 cloud-service 云数据库。
