底图没有加载出来

当前是本地/外部浏览器打开模式：WorkBuddy 的免 key 代理在这里不存在，所以地图是空白的。

解决办法：
1. 回到 WorkBuddy 预览面板打开本文件（零配置）；
2. 点下面的按钮，粘贴你在腾讯位置服务申请的 Key（存在本浏览器，下次打开自动生效）；
3. 或者把 Key 发给小八，帮你写进文件顶部（换电脑也能用）。

设置地图 Key

填你自己在腾讯位置服务申请的 Key，保存在这台设备的浏览器里，下次打开自动生效。
这个 Key 需要开通 WebService API 权限，并把当前域名加进域名白名单：本地预览填 127.0.0.1，线上填 bantian-robot-kids-map.app.workbuddy.host。

微调位置

先在下面选一个点，再到地图上点一下，把它放到准确的位置（最好贴着机器人大道的一侧）。改动会自动记在这台设备，也能复制坐标发给小八写进文件。
